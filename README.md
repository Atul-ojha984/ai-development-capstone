# AI Development Capstone

A capstone project demonstrating AI-assisted software development practices.

## Tech Stack

- Node.js
- JavaScript
- Git
- GitHub
- Cursor AI

## Development Goals

This project will demonstrate:

- AI-assisted development
- Clean Git workflows
- Conventional Commits
- Maintainable project structure
- Clear development conventions

## Getting Started

### Prerequisites

- Node.js LTS
- Git
- Cursor

### Installation

1. Clone the repository and enter the project directory:

```bash
git clone <repository-url>
cd ai-development-capstone
```

2. Replace `<repository-url>` with this repository’s GitHub clone URL.

Application start commands and dependency installation will be documented here once the Node.js implementation is added.
