# Project Development Instructions

## Project Overview

This repository is a capstone project demonstrating AI-assisted software development.

## Technology

- Node.js LTS
- JavaScript
- Git
- GitHub

## Coding Conventions

- Use clear and descriptive names.
- Prefer simple, maintainable solutions.
- Keep functions focused on a single responsibility.
- Avoid unnecessary dependencies.
- Use modern JavaScript syntax.
- Write readable code before optimizing for brevity.

## Git Conventions

Use Conventional Commits for all commits.

Examples:

- `feat: add new functionality`
- `fix: resolve application issue`
- `docs: update documentation`
- `chore: update project configuration`
- `refactor: simplify implementation`

## AI-Assisted Development

When modifying the project:

1. Understand the existing structure before making changes.
2. Make the smallest reasonable change.
3. Explain important implementation decisions.
4. Avoid modifying unrelated files.
5. Review changes before committing.

## Quality

Before considering a task complete:

- Verify that the implementation works.
- Check the Git diff.
- Ensure documentation remains accurate.
- Avoid committing secrets or environment variables.

## Testing

When tests are introduced, run the project's test suite before committing changes.

## Security

Never commit API keys, passwords, access tokens, or other secrets.
